# Synthetic EEG Data Creation for Epileptic Seizure Prediction Model

## Paper Reproduction
**Paper:** *A Generative Model to Synthesize EEG Data for Epileptic Seizure Prediction*  
**Authors:** Khansa Rasheed, Junaid Qadir, Terence J. O'Brien, Levin Kuhlmann, Adeel Razi  
**Published:** IEEE Transactions on Neural Systems and Rehabilitation Engineering (TNSRE), 2021  
**DOI:** [10.1109/TNSRE.2021.3125023](https://doi.org/10.1109/TNSRE.2021.3125023)

## Overview

This repository contains the complete reproduction pipeline for seizure prediction using synthetic EEG data generated by a **VAE-GAN** (Variational Autoencoder - Generative Adversarial Network). The pipeline converts raw EEG signals from the **CHB-MIT Scalp EEG Database** into STFT spectrograms and uses deep learning for seizure prediction.

## Pipeline

1. **Data Preprocessing** — EDF → segmented EEG → STFT spectrograms (PNG images)
2. **VAE-GAN Training** — Generate synthetic preictal (pre-seizure) spectrograms
3. **OC-SVM Validation** — Filter synthetic images using One-Class SVM on deep features
4. **CESP Classifier** — Convolutional Epileptic Seizure Predictor with 4 experiments:
   - **TRTR:** Train Real, Test Real (baseline)
   - **TSTR:** Train Synthetic, Test Real (with anchor strategy)
   - **TRTS:** Train Real, Test Synthetic
   - **TSTS:** Train Synthetic, Test Synthetic
5. **Transfer Learning** — VGG16, VGG19, ResNet50, InceptionV3
6. **Evaluation** — ROC curves, sensitivity, specificity, FPR/h

## CESP Training Parameters (Paper 1)

| Parameter | Value |
|-----------|-------|
| Optimizer | Adam |
| Learning Rate | 1e-4 |
| Epochs | 50 |
| Loss Function | BCE with pos_weight |
| LR Scheduler | ReduceLROnPlateau |
| Cross-Validation | 10-fold Stratified KFold |
| Image Size | 128×128 |
